# 小生活记账簿 · Vant 4 预览

单独的移动端交互方案，入口 `/vant-pilot/`。Vue 3 + Vant 4.9.6，样式和图标均由站点交付，不依赖运行时 CDN。

用合成记录体验流水、日期范围、搜索、记一笔/编辑、礼金详情和统一删除恢复。本轮不设独立人情页，往来资料直接随礼金账目显示。点底部中央的「小簿」进入聊天页，按当前日期与账本对本机示例记录做规则统计，不调用模型。

原型数据只保存在此浏览器（Vant 预览专用存储键），不读取或写入旧原型、礼相记或任何真实账本。不是完整原型的功能替代，不含导入、支付、真实家人共享或同步。

```sh
npm ci
npm run test
npm run build
npm run preview
```

构建输出在本目录的 `dist/`。启动预览后打开 http://127.0.0.1:4173/vant-pilot/ 。
