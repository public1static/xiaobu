# 小生活记账簿 · 产品功能总表

基线日期：2026-11-25。范围覆盖当前 H5 可达业务入口及[小程序一期已确认的交付要求](微信小程序一期PRD.md)。编号用于需求、开发任务和验收用例之间互相引用；新增条目使用新编号。

**读表方式**：「本地」表示有浏览器实现，数据保存在本机；「模拟」表示借本机身份或环境演示外部流程；「部分」表示与目标存在明确差距；「待接入」表示缺少目标能力。「一期」表示 PRD 已纳入，小程序实现及双机验收待完成；「后续」表示 PRD 已明确延后；「待定」表示 PRD 尚未明确排期。同一模块可包含多个阶段。

每节附实现入口及相关测试。条目标注「源码」表示核对过实现，「规则测试」指相关数据或业务规则有自动化覆盖，「既有点测」指此前在桌面浏览器走过该路径。本轮重新运行 H5 自动测试，30 项通过；本轮盘点没有逐项重跑浏览器或进行微信真机验收。

## 一期优先核对的差距

首条流程的步骤、边界和验收环境见[双人共记首条流程规格](../specs/双人共记首条流程规格.md)。

先沿 AUTH-02 → TX-01 → BOOK-04/05 → BOOK-08 验证两人能在各自设备读到同一本账；再用 TX-08/09 验证权限变更、弱网重试和并发。小簿确认卡 ASK-05 应进入同一条流水保存路径。验收金额、署名和权限以一期 PRD 为准。

统计分析、礼单文件导入和礼单导出按已确定范围排除。首页收支汇总归 TX-02，整本备份归 DATA-01。小程序真机、服务器持久化和微信送达目前均缺少目标环境验收记录。
