# 成员权限验收

本轮覆盖 BOOK-03、BOOK-07 和 BOOK-08 的成员新增流水。持有账本的所有者才能查看成员管理列表、变更角色或移除成员。只读邀请默认仍只读；可记账只增加「新增」权限，不新增编辑、恢复或删除流水。

1. 乙按只读邀请加入后，在甲的账本不能记账。甲从「流水 → 成员」把乙设为可记账；乙重新选择此账本，看得到「记一笔」，表单显示甲的账本。甲刷新能看到乙新增的流水。
2. 乙保留另一个表单不提交，甲改为只读，乙再点保存。后端按当前权限拒绝，表单说明未保存，已有流水不变。
3. 所有者确认移除后，乙刷新或查历史时不能读到共享账本；界面返回个人账。已写流水及原审计作者继续保留。旧已用链接和移除前生成的未用链接不能让该成员恢复权限；如确需再次加入，使用移除后生成的新邀请，默认只读。
4. 非所有者无法查看成员管理列表、修改成员权限或移除成员。不做微信真机、统一防重和流水 `submit_key`。

Flyway V4 为现有成员补只读状态与移除时间；保留成员历史记录，保持成员唯一关系。记录流水与成员变更同用账本行锁，避免在旧角色上写入。
