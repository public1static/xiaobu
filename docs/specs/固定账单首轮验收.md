# 固定账单：首轮验收

从「账本 → 固定账单」进入。首轮仅做每月固定金额：保存名称、首次到期日、金额、支出分类和可选常用账户；按月切换待付/已付。31 日遇短月取月底，下个月仍按原计划日计算。未到首期的月份不展示。不做合同、通知、浮动金额、关联旧流水或计划变更。

按月份和状态由后端筛选、分页、返回总数。待付账期由计划和月份推导，不需后台定时任务。付款可确认实际金额、日期和账户；账期和流水同一事务保存，账本写权限和账期唯一约束防止重复入账。已付金额/日期是付款时快照；后续编辑或删除流水不自动重开账期，当前不提供解除关联。只读成员可查，不能创建或付款。

验收：1 月 31 日的计划在 2 月 28 日到期，3 月恢复 31 日；2 月确认一次后只生成一笔正常支出，重新提交不重复生成；相邻月份独立，跨账本请求被拒，列表服务端分页。
