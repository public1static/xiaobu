# 流水更正验收

范围：TX-04、TX-06～08 与并发编辑提示。按原型从详情底部进入编辑或删除；删除需确认，首页「最近删除」可恢复。暂不做永久删除、退款或礼金联动。

1. 编辑沿用记一笔表单，带回原日期、金额、方向、分类、账户和备注。保存后是原流水，不改变原记账人，汇总随之更新。
2. 删除只是标记，正常流水和账户汇总不再包含；最近删除按更新时间显示最多 50 条可维护记录。恢复后计回原日期并保留原作者。
3. 所有者可以维护本账本流水，可记账成员仅能维护自己创建的流水，只读成员不行；每次写入都重新校验当前权限和作者。
4. 两个窗口打开同一笔后，一个先保存、另一个拿旧版本再存，后者收到冲突提示，原表单内容可核对，不覆盖前一次。编辑、删除、恢复都携带已读取的版本。
5. Flyway V6 只增加版本字段；保留原检查和逻辑删除标记。此处是并发更正，不新增统一防重。
