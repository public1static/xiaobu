# 支出记账首轮验收

关联功能：TX-01 支出录入、TX-02 本月流水的最小部分。UI 对照 Vant 原型的流水、记一笔两处。只包含固定个人账的本地 H5 联调；收入、账户、编辑、删除、邀请、AI、生产登录与统一防重组件不在本轮。没有将按钮伪装成已接入的功能。

- 从「记一笔」输入 12.30 元、选餐饮并保存。流水按业务日显示 −¥12.30，刷新后仍能读到同一条。金额不足一分或小数超过两位时不写入。
- 回包不明确时保留表单并提示先回流水确认；提交在途禁用保存按钮。服务端统一防重组件暂未实现，不承诺重放幂等。
- 统一表 ledger_transactions：direction 预留收支方向，本轮只写 EXPENSE；booked_on 为 DATE；created_at、updated_at 为 UTC DATETIME(6)；created_by、updated_by 存身份 ID；deleted 为逻辑删除标记，列表过滤已删除。金额用整数分，分类用稳定编码。不含 submit_key。
- 仅绑定云电脑回环地址；local-expense 是明确的试验入口，不可公开部署。仅使用隔离的 MySQL 5.7 开发库，不读取或写入礼相记或用户刚建的线上库。
