# 账本账户验收

本轮覆盖 ACC-01、ACC-02 与 TX-01 的账户选择。所有者可以新增本账本的普通账户；成员按角色查看、可记账成员可以选用。账户选填，未选不计入任何账户。收支仍用上一轮的默认方向分类，不含自定义分类、账户变更、转账、期初余额或支付平台绑定。

1. 在「记一笔 → 账户」新增「现金」并选中，分别记录收入和支出。打开「账户」，校验已记净额；未选账户的额外流水不影响它。
2. 不同账本可以各自有同名账户，切换账本只显示该账本的账户。通过接口把其他账本的账户 ID 写入当前流水会被拒绝。
3. 显示的「已记净额」只计算本账本、本账户下未删除的收入减支出，不当作银行卡或支付账户的实际余额。
4. Flyway V5 添加账户表与可空流水账户列；保留旧流水，跨账本关联由服务端和数据库双重拒绝。

## 账户管理原型对齐

账户按 Vant 原型的资金、信用、投资、预付四组展示。选择类型后创建，金额留空表示待填。所有者可以修改名称、类型、当前金额与启用状态；历史记录通过账户 ID 保持关联。原有已知余额保留。停用后仅历史记录可保留原账户。
从账户详情查全部日期的收支、退款和双向转账，点流水回到原单。普通账户发起转账、信用账户记还款、投资账户记买入或赎回。管理员可维护全账本转账，可记账成员仅维护本人转账，只读成员只能查看。转账的修改与撤销同步影响两端余额。选择器支持搜索名称、类型和分组，新增后选中。
