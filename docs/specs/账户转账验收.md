# 账户期初与转账

- 流水页点「账户」，查看账户的期初余额和账面余额；打开记账表单里的选账户时，只做账户选择，不显示转账管理。
- 所有者新增账户时可填期初余额，留空为 0，初始欠款可填负数，最多 8 位整数和 2 位小数。已有账户迁移后期初为 0，不改写既有流水。
- 账本有两个账户时，所有者和可记账成员可从账户页录入转账：转出、转入、金额、日期必填，备注选填。只读成员可看余额和最近转账，不可新增。转账仅用于记账，不连接金融机构，不校验实际余额。
- 账面余额 = 期初 + 该账户的已入账收支净额 + 转入 − 转出。转账不产生收入或支出，不进入月度收支统计或流水列表；在账户页以已记日期倒序展示最近 50 笔。目前不提供转账编辑和删除。
- 单笔转账存一条记录；两个账户必须不同且属于同一本账，应用权限检查与数据库联合外键防止跨账本。期初、流水、转账都以整数分计算。
- 接口：现有账户 POST 增加可选 `openingBalanceCents`；账户响应增加 `openingBalanceCents`、`balanceCents`，原 `recordedBalanceCents` 定义不变。新接口 GET/POST `/api/v1/ledgers/{ledgerId}/account-transfers`。
