# 分类管理验收

范围：第 11 步，个人或共记账本的收入、支出分类。默认分类仍在；新增、调整顺序与停用从记账表单的「分类管理」进入。账本所有者可以管理，可记账成员只能选本账本分类。

- 已讨论的 Vant 4 原型是正式界面的对照。流水页右下是圆形铅笔悬浮按钮「记一笔」；进入弹层或只读账本时隐藏。
- 记账、编辑共用两行图标快捷分类；超出一屏可横滑。本页与「分类管理」面板共用图标和排列规则。所有者可在面板里直接点选或拖动，点右上「新增」行内填写，保存后自动选中。不用切换管理模式。
- H5 支持键盘方向键。停用与恢复入口保留可点击的上移、下移，无须拖动。排序保存后重新打开或刷新仍保留。微信若只通过编译，不视为真机验收。
- 停用不删除分类或历史账，查账和详情仍显示原分类；不再用于新增。修改旧账备注可保留原停用分类，也可换成启用分类。可恢复停用分类。
- 同方向不允许重名，至少保留一个启用分类。不同账本隔离；服务端拒绝越权改目录、跨账本使用自定义类别、类别与方向不一致。
- V8 只新增分类表。未迁移旧流水；已有类别代码继续可用。原型中超出当前业务范围的礼金联动、助手和待办没有随本次界面对齐启用。
