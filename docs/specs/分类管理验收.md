# 分类管理验收

范围：第 11 步，个人或共记账本的收入、支出分类。默认分类仍在；新增、调整顺序与停用从记账表单的「分类管理」进入。账本所有者可以管理，可记账成员只能选本账本分类。

- 快捷分类两行横滑；面板直接选用或新增。新增成功自动选中。
- H5 可用手柄拖动，亦可用上移/下移。保存后重开或刷新顺序仍在。微信预览编译只验证上移/下移入口，不代替真机验收。
- 停用不删除分类或历史账，查账和详情仍显示原分类；不再用于新增。修改旧账备注可保留原停用分类，也可换成启用分类。可恢复停用分类。
- 同方向不允许重名，至少保留一个启用分类。不同账本隔离；服务端拒绝越权改目录、跨账本使用自定义类别、类别与方向不一致。
- V8 只新增分类表。未迁移旧流水；已有类别代码继续可用。
