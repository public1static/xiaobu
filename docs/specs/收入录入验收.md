# 收入录入验收

范围：TX-01 与 TX-02 的收支部分。沿用同一张流水表、同一套账本权限和「记一笔」。仅基础收入分类，不含工资明细、账户管理、退款或统一防重。

1. 从「记一笔」先保存 12.30 元餐饮支出；再打开表单切到「收入」，可选工资、奖金、兼职、其他收入。切换方向清空旧方向分类，不丢金额。
2. 记录测试工资 ¥5,000.00，流水出现绿色的正向金额，支出仍为 ¥12.30，收入为 ¥5,000.00，结余为 ¥4,987.70；刷新后不变。
3. 通过接口提交不匹配的分类、非法的收支方向或非正整数分，均拒绝。未加入的其他身份和只读成员不能写入。
4. 不改数据库结构或已保存的支出 ID。新入账使用流水 ID 前缀，收支以方向字段为准；历史支出照常显示。
5. 本地试验端统一使用 `GET/POST /api/v1/ledgers/{ledgerId}/transactions`，替代之前仅支出入口。联调用 `python3 scripts/verify-ledger-h5.py 4173`。
