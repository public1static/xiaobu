# 查账和流水详情验收

范围：TX-02 日期筛选与 TX-03 详情。对照 Vant 原型，将日期入口放在汇总区、备注搜索放在流水上方，点一行从底部打开详情。前端正式工程用 uni-app 日期选择器；不迁入礼金、退款、编辑等未启用入口。

1. 按月浏览不受影响；指定开始和结束日期可跨月，首尾都包含，最多 366 天。不完整或倒序日期会提示。
2. 备注搜索和日期范围可叠加。流水、收入、支出与筛选结余同步更新；清除后恢复所选月份。清空结果时提示没有匹配流水。
3. 点开流水显示分类和金额，其下是记账日期、记账人、账户及已有备注。自己显示「我」，同行有效成员显示其测试名称。
4. 查询始终在当前账本；切换账本不分享数据。非成员不能通过流水 ID 查到详情，已删除流水不会返回。本轮不改数据库结构。
