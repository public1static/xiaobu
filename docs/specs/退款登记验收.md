# 退款登记验收

- 从原支出详情进入「登记退款」。收款、转账以及已全部退清的支出不提供入口；沿用原流水的维护权限。
- 只录入到账金额、日期和可选到账账户。允许多次部分退款，合计不得超过原付款；日期须介于原付款和今天（北京时间）之间。
- 原支出及付款账户不随退款登记改写。详情显示原付、已退、实付和各次到账记录。
- 流水按到账日期显示「分类 + 退款」，点击返回原支付详情。当前筛选期间内的退款冲减该期间的支出，不计入收入；只有退款的期间，净支出允许为负。选择到账账户时只给该账户加回对应金额，未选择时不影响账户余额。
- 改账不能把原支出改为收入、把原付改成小于已退金额，或把付款日期推迟到已登记退款之后。逻辑删除原支出同时从流水和账户余额移除相关退款；恢复原支出时一并恢复。退款不从最近删除单独出现。
- 本轮只登记已到账退款，不发起退款，不单独修改/撤销退款，不增加统一防重复提交组件。
