# 自建单次提醒首轮验收

- 入口为「首页铃铛 → 待办 → 新增」。填写内容，选择事项日期、提前天数和时刻，保存前预览实际提醒时间。首版只做公历单次，提前 0/1/3/7 天，时间按北京时间精确到分钟。已过的时间可补记，立即进入待处理。
- 自建提醒只给创建者本人，即使在家庭账本中也不公开标题、详情、计数或办结记录。接续现有账本写权限：只读成员可看共有业务待办，不可新增；写成员可维护自己的提醒，不能读写别人的提醒。
- 未到提醒时间显示「已计划」，已到且未处理进入「待处理」并计入铃铛；事项日期仍用于列表排序。详情可编辑未办结提醒。可在列表快速标记已办并撤销，已完成详情也可撤销办结。保存或办结提醒均不生成流水、不处理合同或固定账期。
- 本期不发送通知，不接农历、节日、重复和业务关联，不在页面展示不可用的入口。其余完整交互见 Vant 4 原型。
- V29 以业务表保存自建内容、日期、实际提醒时间、办结及审计字段，业务提醒时间按北京时间解释，审计时间仍用 UTC。自建提醒通过第三个待办来源接入统一列表、数据库分页及计数。聚合查询上下文传入账本、当前操作者与同一北京时间；每个来源自行施加该来源的访问权限和到期规则。前端注册详情目标和可选办结动作，其他来源仍回自己的页面，不判断分类。
