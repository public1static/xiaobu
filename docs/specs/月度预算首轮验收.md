# 月度预算：总额、已用与剩余

入口为「账本 → 月度预算」，不在首页添加默认餐饮预算。沿用流水页所选月份和现有账本，支持前后查看月份至本月；账本切换后不沿用其他账本的预算。首轮只有总预算，无按分类预算、自动续用、预算提醒、强制限制或预算删除。

- 未设置时仍显示净支出，不把未设置当成 0 元；可记账成员可设置、修改，所有者和有效成员可查看。只读状态不出现写入口，接口从会话复核账本权限。
- 已用等于流水页当月净支出：以业务日期为准，退款按到账日抵扣，可能为负；收入、转账和押金不计。删除或恢复流水后重新打开可读到最新结果。整月汇总在数据库完成，不从一页流水推算。
- 剩余 = 总预算 − 已用。小于零时显示「已超出」及超出金额；超额不阻断记账。预算仅作用于指定账本和自然月，不修改流水。
- V27 增加 `ledger_monthly_budgets`，用当月第一天的 DATE 存月份，账本与月份唯一，金额使用整数分，保留创建人、更新人、审计时间和逻辑删除标记。设置预算在账本写锁内完成。
- 接口：`GET /api/v1/ledgers/{ledgerId}/budgets/monthly/{month}` 查看，`PUT` 提交 `amountCents`。返回该月预算、净支出及剩余；没有预算时总额和剩余为空。

## 验证

- 云端 Chrome 390 px H5 + Java API + 独立 MySQL 5.7.44：未设置、录入、修改、超额、月份隔离、刷新保留、只读界面。样例总额 3,000 元，已用 2,380 元，剩余 620 元；修改总额为 2,200 元后显示超出 180 元。收入、账户间转账和押金不计入，退款只抵扣一次。
- 后端验证超过一页的整月统计、跨月退款、删除与恢复、权限及审计；55 项通过。前端格式、17 项测试、H5 与微信小程序构建通过；微信未做真机验收。
